# Gestion de mon compte — Android Studio

Projet Android Studio généré à partir de la version HTML améliorée.

## Fonctionnement
- Interface locale dans WebView.
- JavaScript activé.
- DOM Storage activé pour la sauvegarde locale.
- Aucune connexion Internet requise pour l'application.

## Ouvrir
Ouvrir le dossier `GestionCompteAndroid` dans Android Studio.

## Construire l'APK
Android Studio → Build → Build APK(s).

L'APK debug sera normalement créé dans:
`app/build/outputs/apk/debug/app-debug.apk`
